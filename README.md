# Codyssey

Codyssey 개발 입문 과정의 과제 산출물을 과제 코드별로 정리한 저장소입니다.

## 과제 구조

```text
codyssey/
├── E1-1/                       # 개발 워크스테이션 구축
├── E1-2/
│   ├── quiz-game-practice/     # Python 퀴즈 게임 원본
│   └── quiz-game-practice-clone/ # Git clone/pull 실습 복제본
└── E1-3/                       # Mini NPU Simulator
```

### E1-1 — 개발 워크스테이션 구축

터미널, Docker, Git/GitHub를 사용해 재현 가능한 개발 환경을 구축하고 검증한 기록입니다.

- 상세 문서: [`E1-1/README.md`](E1-1/README.md)

### E1-2 — Python 퀴즈 게임

Python 기본 문법, 객체 지향 설계, JSON 파일 입출력과 Git 작업 흐름을 연습한 CLI 퀴즈 프로그램입니다.

- 원본 프로젝트: [`E1-2/quiz-game-practice/`](E1-2/quiz-game-practice/)
- clone/pull 실습본: [`E1-2/quiz-game-practice-clone/`](E1-2/quiz-game-practice-clone/)

### E1-3 — Mini NPU Simulator

MAC 연산으로 패턴을 판별하고 연산 복잡도를 확인하는 콘솔 프로그램입니다.

```bash
cd E1-3
python3 main.py
```
