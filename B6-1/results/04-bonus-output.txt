--- [함정 실증] NOT IN 은 목록에 NULL 이 섞이면 결과가 통째로 빈다 ---
(준비) 함정을 재현하려고 담당 미배정 학생을 한 명 만든다
담당미배정학생수
--------
1       
(A) NOT IN + NULL 이 섞인 목록  -> 결과가 0행으로 사라진다
(B) NOT EXISTS 로 같은 질문  -> NULL 과 무관하게 정상 동작
id  담당학생없는선생님
--  ---------
8   임수빈      
10  한가람      
(C) NOT IN 을 고치려면 서브쿼리에서 NULL 을 먼저 걸러야 한다
id  담당학생없는선생님
--  ---------
8   임수빈      
10  한가람      
(정리) 담당을 다시 배정해 원래 상태로 되돌린다

--- 세 방식의 실행계획 비교 ----------------------------------------
[LEFT JOIN]
QUERY PLAN
|--SCAN s
`--SEARCH c USING COVERING INDEX idx_consultation_student (student_id=?) LEFT-JOIN
[NOT IN]
QUERY PLAN
|--SCAN s
`--USING INDEX idx_consultation_student FOR IN-OPERATOR
[NOT EXISTS]
QUERY PLAN
|--SCAN s
`--CORRELATED SCALAR SUBQUERY 1
   `--SEARCH c USING COVERING INDEX idx_consultation_student (student_id=?)
